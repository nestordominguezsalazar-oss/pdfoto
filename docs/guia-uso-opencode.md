## 🚀 Cómo usarlo con opencode

Una vez tengas estos archivos en tu repo:

```bash
# 1. Inicializar proyecto Android base (o dejar que opencode lo haga)
mkdir pdffoto && cd pdffoto
git init
# ... crea README.md y docs/ con el contenido de arriba

# 2. Arrancar opencode
opencode

# 3. Prompts sugeridos en orden:
# "Lee README.md y AGENTS.md. Luego ejecuta el paso 1 del orden de implementación."
# "Continúa con el paso 2."
# "Implementa el paso 6 y sus tests unitarios."
